# Django-проект "Интернет-магазин"

Django-проект интернет-магазина. Отображает главную страницу и страницу с контактами,
на которой можно оставить обратную связь.


## Установка
Клонирование репозитория на локальный репозиторий:
1. Чтобы клонировать репозиторий с GitHub себе на компьютер, необходимо
получить ссылку на доступ к репозиторию в разделе **Code** на странице
репозитория, выбрать способ взаимодействия с GitHub (**HTTPS**) и **скопировать**
ссылку на репозиторий для клонирования.
2. В главном меню **PyCharm** перейдите в меню **Get from VCS**. 
3. Вставьте ссылку на репозиторий и нажмите на кнопку **Clone**.
4. По окончании клонирования будет открыт проект, вы можете работать с этим проектом.


## Использование
### Начало работы
1. Для начала необходимо запустить локальный сервер.
Чтобы его запустить, введите команду `python manage.py runserver` 
и перейдите по ссылке, которая появится в консоли.
2. Чтобы перейти на главную страницу, добавьте к URL-адресу `/home_page`.
3. Зарегестрируйтесь на сайте или войдите в существующий аккаунт.
4. После регистрации Вам придет приветственное письмо на почту.

### Сущности проекта:
- Продукт
- Категория продукта
- Стаьи блога

### Авторизация и права доступа
Авторизованные пользователи могут просматривать, создавать, изменять и удалять 
продукты. Общедоступна лишь страница просмотра списка товаров.

Редактирование и удаление продукта доступно только владельцу.
Модератор может только снять продукт с публикации.

Чтобы перейти на страницу с контактами, добавьте в адрусную строку `/contacts`.
На данной странице можно отправить форму обратной связи
и получить ответ об успешном отправлении.

### Блог
Приложение блога релизует функции по управлению статьями. Блог поможет улучшить
видимость сайта в поисковых системах и привлечь больше посетителей. Посты в
блоге имеют счетчик количества просмотров. Также пост можно снять с публикации,
не удаляя сам пост.
